# MIIC-derived visual asset notice

The two PNGs in this directory are small, annotated figures rendered from the
MIIC final-test set by the project's failure-analysis code. They are included
solely to make the public research README understandable.

- Source dataset: **MIIC — Microscopic Images of Integrated Circuits**
- Source DOI: `10.21979/N9/WBLTFI`
- Dataset license: **CC BY-NC 4.0** (non-commercial research use)

These figures are **not** covered by the repository's MIT software license.
Keep their attribution and license notice with any permitted redistribution.
If a downstream use needs a code-only / permissively licensed repository,
remove this `miic_examples/` directory before publishing. No raw MIIC archive
or unannotated image is included here.

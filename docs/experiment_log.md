# Experiment log template

Record every run with UTC timestamps, protocol version, configuration hash,
source revision, artifact hashes, device, runtime, batch size, and outcome.

| UTC | Run | Protocol | Purpose | Inputs frozen? | Result / decision |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

Do not replace a final-test result in place. A correction after a final-test
inspection requires a new protocol version and an explicit post-hoc label.
